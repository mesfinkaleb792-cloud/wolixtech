# WOLIX | Smart Schedule + Attendance Tracker

## Description
WOLIX is a personal learning project built by **Mesfin Kaleb** to track daily schedules, attendance, and progress while learning Full-Stack Web and Android Development.  
This is the **first website created under WOLIX**, serving as a live dashboard for daily activities, study plans, and development milestones.

## Features
- **Real-time Daily Schedule:** Visual timeline for Morning, Afternoon, Evening, and Night sessions.  
- **Attendance Tracker:** Pop-up modal for marking attendance during classes or study sessions.  
- **5-Month Dual Track Roadmap:** Full-Stack Web Development and Android Development timelines.  
- **Progress Bars:** Visual indicators for task completion across study and development blocks.  
- **Responsive Design:** Works on desktop and mobile devices.  
- **Interactive UI:** Accordion panels, countdown timers, and live schedule updates.
